01 Receiver

Where your applications send OTLP telemetry.

Loopback is the safer default for local testing.

02 Filtering rules

Drop a log record when its attribute matches a configured value. Use one rule per line.

Example: http.route=/health. Rules are combined with OR semantics: a record matching any rule is dropped.

03 Local archive

Preserve original log records separately from the filtered pipeline.

Ensure the Collector's operating-system user can write to this path and that disk retention is managed.
